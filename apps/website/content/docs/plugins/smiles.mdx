The `@streamdown/smiles` plugin renders [SMILES](https://en.wikipedia.org/wiki/Simplified_molecular-input_line-entry_system) molecules and reaction schemes in the browser using [SmilesDrawer](https://github.com/reymond-group/smilesDrawer). The engine stays out of your bundler graph until you import the engine entry, and it only runs when a `smiles` or `smi` fence is actually rendered.

- Interactive controls (fullscreen, download SVG/PNG/SMI, copy, pan/zoom)
- CPK element colors, with an optional monochrome theme
- Toolbar toggle between skeletal structures and compact Wikipedia-style notation (`CH₃`, `COOH`)
- Reaction SMILES (`reactants>reagents>products`) start in compact drawing; molecules start skeletal
- Custom error handling with retry

## Install

```package-install
npm install @streamdown/smiles smiles-drawer
```

`smiles-drawer` is an optional peer dependency: importing the engine entry is what pulls it into your bundler's module graph, so apps that don't use the plugin never bundle it.

## Usage

```tsx title="chat.tsx" lineNumbers
import { createSmilesPlugin } from '@streamdown/smiles';
import { engine } from '@streamdown/smiles/engine';

const smiles = createSmilesPlugin({ engine });

<Streamdown plugins={{ smiles }}>
  {markdown}
</Streamdown>
```

Without the plugin, SMILES code blocks render as plain code.

## Language identifiers

````markdown
```smiles
CC(=O)Oc1ccccc1C(=O)O
```
````

`smi` is accepted as an alias of `smiles`.

Reaction SMILES use `>` to separate reactants, reagents, and products:

````markdown
```smiles
CCO.CC(=O)O>>CC(=O)OCC
```
````

## Options

Pass `errorComponent` or `config` on the `smiles` prop (same shape as Mermaid):

```tsx
<Streamdown
  plugins={{ smiles }}
  smiles={{
    config: { theme: "auto", elementColors: true },
    errorComponent: MySmilesError,
  }}
>
  {markdown}
</Streamdown>
```

- `config.theme` — `"auto"` (default, follows the page dark theme), `"light"`, `"dark"`, or `"oldschool"`
- `config.elementColors` — set `false` to force monochrome (`oldschool`)
- `config.compactDrawing` — `true` concatenates terminals (`COOH`, `CH₃`); `false` draws full structures. When omitted, reactions default to compact and molecules to skeletal. The block toolbar can override this per diagram.
- `config.width` / `config.height` — canvas size in CSS pixels (default 320×220)
- `controls.smiles` — toggle download, copy, compact notation, fullscreen, and pan-zoom
